Simplified language inference
program ::= sLs //every sL of the program has form C[Xs]:Ts{sMs}
//Core language
e   ::= x | L | e.m[Ts](es)
L   ::= C[Xs]:Ts{Ms}
M   ::= m[Xs](x1:T1..xn:Tn):T; | m[Xs](x1:T1..xn:Tn):T->e;
T   ::= X | C[Ts]
//Inference layer
ie  ::= x:iT | iL:iT | ie.m[iTs](ies):iT | ie.m(ies):iT
iL  ::= C[Xs]:iTs{iMs} | {iMs}
iM  ::= m[Xs](x1:iT1..xn:iTn):iT; | m[Xs](x1:iT1..xn:iTn):iT->ie;
iT  ::= ? | X | C[iTs] | Err
//User surface language
se  ::= x | sL | se.m[Ts](ses) | se.m(ses)
sL  ::= C[Xs]:Ts{sMs} | {sMs}
sM  ::= m[Xs](x1:T1..xn:Tn):T; | m[Xs](x1:sT1..xn:sTn):sT->se;
sT  ::= T | ?
Γ   ::= x1:iT1 .. xn:iTn
//Note: in this restricted language
//- a method of a sL of the program has no ? in the signature
//- a literal with a name inside a method body has form C'[Xs]:C[Ts]{sMs} (exactly one supertype), and has type C[Ts]
//- a literal inside a method body can ONLY define methods in C (not new ones), all with a body
Pipeline for every method body of a sL of the program
containing a surface expression se under Γ (including 'this') with return T

- ie := inferenceOf(se, T)
- Γ ⊢ ie ==>* Γ' ⊢ ie' //Γ and T extracted from the method signature
- lower(se,ie') = e
- Γ ⊢ e : T //finally, typing the method body
//Note: inferenceOf(se,T) annotates se with T, a literal C'[Xs]:C[Ts]{sMs} with C[Ts], and all the rest with ?

Obvious selectors:
- typeOf(ie) = iT
- withType(ie,iT) = ie'
- methodHeader(iT,m) = iTs; C[Xs]; m[Xs'](x1 : T1 .. xn : Tn) : T0
- methodHeader(ie,m)= methodHeader(typeOf(ie),m)
//Note: methodHeader(C[iTs],m) do not already apply [Xs=iTs], instead produces a triple
//iTs;C[Xs]; m[Xs'](..) that are ready to use in the needed context using appropriate alpha renaming
//Here iTs is returned even if part of the input for convenience, so other parts of the rules can just use it
//Note: m can be inherited by C[Xs] from a supertype C'[Ts']; then T0..Tn already have
//the type parameters of C' replaced with Ts'

#Define close_Xs(iT) = iT'    close_Xs(iTs) = iTs'
